# Symphony Quantitative Transformation Vector Intent

## Purpose

The Symphony Quantitative Transformation Vector (SQTV) owns selected native research-data representation conversions and derived transformations beneath SQV.

## Scope

SQTV defines exact input and output domains, schema and representation versions, numerical and time semantics, loss characteristics, bounded preparation workspace, failure outcomes, and output lineage. First-party converters and transformation engines are native C++.

## User Choice and Neighbor Boundaries

The user chooses whether to convert or transform data, the operation and its parameters, and any permitted information loss. SQTV does not impose a canonical format or normalization funnel. Source observations remain attributable; derived output never silently replaces them.

SQTV authors evidence for its own derived outputs but does not acquire source data (SQAV), own dataset description and catalogue contracts (SQMV), own movement and leases (SQFV), retain data (SQPV), or decide consumer access and delivery (SQDV). It does not perform SBV-owned backtest calculations or define user strategy logic.
