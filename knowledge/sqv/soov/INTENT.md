# Symphony Orchestra Omega Vector Intent

## Purpose

The Symphony Orchestra Omega Vector (SOOV) is SQV's high-performance C++-only FIX architecture.

## Origin

The historic QuanuX FIX architecture is SOOV's rough draft and research source. It is input for future design, not automatically canonical Symphony behavior.

## Scope

SOOV will own the Symphony-authored FIX framework surfaces later ratified by the Architect.

## Non-Scope

SOOV does not define user strategy logic, make FIX mandatory, absorb non-FIX broker/data APIs, or claim that its detailed session, message, symbol, recovery, and adapter architecture has already been decided.
