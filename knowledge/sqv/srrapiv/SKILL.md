# Working with SRRAPIV

Read SPEC.md, BINDINGS.md and MAINTENANCE.md before changing native mappings or version semantics. Inspect the selected installed engine through `qxctl sqv rithmic api describe` and its exact schema/template resources. Never infer support from another SDK version or from FIX behavior. Use a private explicit runtime configuration and retain the returned generation. Inspect attempts after uncertain effects before deciding on another request. Keep vendor credentials, SDK archives and account observations outside source control.
