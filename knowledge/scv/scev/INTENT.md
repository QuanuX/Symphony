# Symphony Cloud Edge Vector Intent

## Purpose

Edge-provider family knowledge, preserving distinct product and service boundaries. This semantic owner is subordinate to `knowledge/scv/SPEC.md` within SCV. It keeps native source meaning before optional common capability projections.

## User Choice

The owner records evidence, explicit requirements, unknowns and qualified possibilities. Family membership does not assert equivalence, rank vendors, exclude cross-family composition, or prohibit user-defined modules and bridges. The user controls source selection, assumptions, policy and operational action.

## Installation Independence

The C++ engine `symphony-scev` can be independently installed and invoked. Neither its parent engine nor another provider engine must be installed. Exported, digest-bound knowledge can be supplied to parent composition; the parent owns its own comparison and search result.
