# Symphony Markdown Conversion Vector Intent

## Purpose

The Symphony Markdown Conversion Vector (SMCV) is an optional SIV translator that allows an agent-facing IPC exchange to remain precise Markdown while converting to or from the exact machine representation required by the receiving Symphony contract.

## User Control

SMCV is enabled or disabled through a future qxctl control. Configuration may vary by applicable installation, connection, agent, Node, or other ratified scope rather than becoming a universal platform requirement.

## Non-Scope

SMCV does not create meaning, repair invalid content, authorize an operation, replace JSON or another owner format, become canonical storage, or require all agents and components to use Markdown.
