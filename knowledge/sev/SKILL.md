# Symphony Evolution Vector Skill

## Purpose

Guide authorized callers through deterministic change admission, impact assessment, disposition planning, recalculation, verification, recovery, and closure.

## Required Reading Order

1. `knowledge/sev/INTENT.md`
2. `knowledge/sev/MANIFEST.md`
3. `knowledge/sev/SPEC.md`
4. `knowledge/sev/DISPOSITIONS.md`
5. the selected profile, including `profiles/qxctl-command-surface.md`
6. `knowledge/sav/SPEC.md`
7. `knowledge/FEATURE-ADMINISTRATION.md`
8. `knowledge/LIFECYCLE.md`
9. `knowledge/TIME.md`
10. owner contracts for every affected surface

## Procedure

1. Obtain one exact SAV CURRENT snapshot and preserve its scope and coverage state.
2. Admit one bounded planned-change or novelty envelope with a stable semantic fingerprint.
3. Validate affected Accord References, features, commands, engine operations, packages, bindings, and receptors.
4. Run `impact_assess` and inspect every unresolved owner or missing consequence.
5. Run `disposition_plan`; distinguish hard safety dependencies from reorderable ready actions.
6. Treat the plan as non-authoritative evidence.
7. For mutation, obtain a fresh exact SSIAG decision and prepare through the existing coordinator lifecycle circuit.
8. Let qxctl execute one reviewed external action, then fully reobserve the host.
9. Recalculate from observed evidence; do not mark an action complete from exit status alone.
10. Verify and close only when the declared target is proven or explicitly abandon with preserved evidence.

## SCSEV Procedure

Supply the SSFV semantic snapshot, feature-administration profile, expected and optional observed qxctl registries, engine descriptors, and caller-declared command proposal. The profile reports exact missing consequences and proposal constraints. It does not invent final names, grammar, permissions, exemptions, or tests.

## Stop Conditions

Stop on unknown critical protocols, stale source CURRENT, ambiguous ownership, missing hard dependency, incomplete qxctl consequences, incompatible version negotiation, indeterminate partial delivery, or an unratified canonical write.

## Non-Authorization Statement

This skill does not grant permission, apply a plan, mutate a coordinator journal directly, write qxctl commands, make a module integration-ready, or export novelty without a separate explicit decision.
