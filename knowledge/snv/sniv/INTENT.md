# Symphony Node Identity Vector Intent

## Purpose

The Symphony Node Identity Vector (SNIV) records the identity and physical continuity of a Node across provider, owned-hardware, Symphony, and user evidence.

## Scope

SNIV distinguishes the physical Node, provider-resource identity, selected provider-offering reference, infrastructure-domain identity, Symphony Node identity, Node incarnation, and relevant predecessor or retirement lineage. SCV owns the provider catalog meaning; SNIV records the particular Node's association.

## Non-Scope

SNIV does not own resource inventory, cluster membership, user-facing name resolution, hardware capability comparison, provisioning, or provider selection.
