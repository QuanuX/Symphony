# Symphony Consolidated Naming Vector Intent

## Purpose

The Symphony Consolidated Naming Vector (SCNV) maps the different names already associated with one SNV subject so users and tools may resolve those names within their valid scopes.

## Scope

SCNV is strictly bounded to SNV subjects: Nodes, Node incarnations, Node resources where separately named, clusters, and their SNV relationships.

## Non-Scope

SCNV is not Symphony's universal namespace authority. It does not name components, vectors, features, commands, protocols, providers, brokers, strategies, or other non-SNV subjects.
