# Symphony Cluster Identity Vector Skill

## Procedure

1. Resolve each physical Node and applicable incarnation through SNIV.
2. Identify the user-established cluster identity and scope.
3. Require evidence of one or more bus connections among participating Nodes.
4. Preserve each bus relationship without multiplying cluster identity automatically.
5. Keep desired topology separate from observed connectivity.

## Stop Conditions

Stop before defining cluster cardinality beyond the ratified minimum, membership-retention rules, bus identity syntax, connectivity polling, routing, or cluster creation behavior.
