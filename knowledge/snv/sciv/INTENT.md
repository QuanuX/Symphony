# Symphony Cluster Identity Vector Intent

## Purpose

The Symphony Cluster Identity Vector (SCIV) records cluster identity and the bus-connected relationships through which Nodes form that cluster.

## Scope

SCIV distinguishes cluster identity, participating Node incarnations, bus or fabric relationships, and Node-in-cluster references including alternate-bus relationships.

## Non-Scope

SCIV does not create a cluster, connect a bus, name a Node, define bus behavior, or infer connectivity from desired topology alone.
