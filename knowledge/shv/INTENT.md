# Symphony Hardware Vector Intent

## Purpose

The Symphony Hardware Vector (SHV) owns hardware-capability knowledge that helps users understand how physical design can enable, constrain, port, or extend quantitative software.

## Scope

SHV may cover processors, CPU core types, GPUs, NICs and fibre interfaces, motherboards, cache hierarchies, memory, NVMe, complete system builds, and other evidenced physical capabilities relevant to program design.

## Time Horizon

The default core coverage starts in 2018 and extends through a caller-supplied as-of date. The initial date basis is model introduction, never an inferred individual manufacture date. Users may expand, narrow, replace or remove this filter through qxctl coverage profiles. Default coverage is a research starting point, not hardware admission policy.

## Non-Scope

SHV does not identify a user's Node, allocate hardware, select a provider, recommend a trading strategy, or claim that one benchmark determines algorithmic suitability.
