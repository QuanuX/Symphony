## Use

Create only in a selected empty root. Reopen with the exact original manifest and
options. Interpret `duplicate` as exact retained retry with the original receipt.
Interpret `outcome_uncertain` as requiring close/reopen reconciliation before any
further operation. Preserve staging and committed evidence while diagnosing
conflicts, corruption or missing records. The library exposes no deletion API.

Run focused native and installed-consumer checks for modified contract boundaries.

selected process-crash contract; they do not certify power-loss durability.
