# Native Cloudflare administration intent

Supply an independently installed native SOV owner for exact Cloudflare CLI administration through qxctl. Keep provider knowledge at SCEV-CF, credential ownership and use authority at SSIAG, and append authority at STAV. Support explicit unprivileged composition without ambient account, runtime or credential selection. Preserve the existing SSH v1 contract and separately governed optional transport profiles.

The optional I5 Access helper owns user-session bytes and connects only through an
explicit protected profile. It preserves separate provider, profile and target
admission and keeps SSH v1 unchanged.
