# SQTV Integer Conversion C++ Intent

Preserve exact mathematical integer values while changing their declared width,
signedness or byte order. Publish a derived immutable SQFV batch with an exact
SQMV manifest that retains source, units, time and access evidence and records
its input and operation lineage. Reject an entire batch when any value cannot
be represented exactly. This first C++26 library admits one narrow representation
domain; other data formats and research transformations require their own contracts.
