# SQPV inspection administration skill

Read SPEC and OWNER-INTERFACE before use. Supply an exact prefix, release and bounded JSON input. Treat templates as unanswered forms. Result digests bind evidence, not authorization. Native errors intentionally omit input paths and payloads.

For retained-state observations, use the physical absolute root on macOS local APFS or the caller-selected Linux filesystem. Linux support includes Ubuntu LTS x86_64/ARM64 and the shared DGX Spark ARM64 code path; do not treat generic ARM CI as physical Spark/DGX OS or GPU qualification. Preserve all path, shared-lock, stat/inventory, bounds and identity checks, and the owner's dirty-state refusal or reporting behavior. Do not infer persistence from successful syscalls or recover a store through an inspection command. Native Windows is unsupported.
