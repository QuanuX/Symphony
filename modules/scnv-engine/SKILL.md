# SCNV engine usage

1. Obtain exact supplied association evidence. Keep assigned names, sources, typed subjects, exact TOPS/TROG/cluster scopes and effective intervals explicit.
2. Inspect the installed descriptor and version. Use receipt-owned `schemas/v1/names.schema.json`, `resolve.schema.json` and `admin.templates.json` for the selected release.
3. Validate records or produce a typed proposed transition with the exact predecessor evidence digest and naming-policy revision.
4. Resolve the exact desired scope/time; qualify namespace/kind when appropriate. Treat ambiguous, insufficient and unsupported results explicitly.
5. Bind a unique result's immutable subject and snapshot to a later prepared operation. Reuse or reassignment never redirects that binding.
6. Pass proposed records to the separately selected retention/selection workflow. Pure validation is not a durable change.

No prompts, implicit global search, dynamic version selection, provider calls or undisclosed dependencies are part of these operations.
