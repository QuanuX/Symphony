# SHV profile engine operating contract

Discover the exact installed schema and unanswered templates through
`qxctl shv profile schema|template`. Compile the caller's class metrics, diagnose
mapping declarations, build the caller's portable universe and bind explicit local
source and decoder roots. All commands require an exact prefix and version.

Treat conformance as declared vocabulary correspondence, not source extraction or
hardware qualification. Use the bind catalogue through the existing kernel controls
for source replay, requirements or graph projection. Actual activation and publication
retain their separate qxctl owners and permissions. Preserve old sealed artifacts.

For exact 0.2.0-dev, use `qxctl shv mapping diagnose-source` for individual field
replay failures, and `qxctl shv references analyze` for caller-selected artifact
reference paths. An unreachable candidate is not permission to delete evidence.

For an interface-authoring change, update OWNER-INTERFACE.json, run `python3 modules/shv-profile-engine/tools/generate_interface.py`, and check frozen history, generated drift and independent semantic regressions. Normal engine operation requires no generator. Select 0.3.0-dev explicitly to use receipt-bound interface admission; existing defaults remain unchanged.
