# SCIV engine operating procedure

1. Supply exact user-established cluster/system references and identified Nodes. Preserve physical, incarnation and bus identities as distinct fields.
2. Supply attributed membership and connection records with known times; omit unknown times. Select explicit direction, transitivity, freshness and evaluation time.
3. Call `sciv_validate`, or prepare a typed attributed addition through `sciv_transition` with the replayed expected digest.
4. Inspect source references, membership, each bus and uncertainty. Current disconnection preserves historical Node and cluster records.
5. Pass original evidence and its exact owner release to SNV retention/composition as requested. A result digest does not substitute for original-evidence replay.

Stop before accepting unknown protocols, inventing Nodes/incarnations, implying an undocumented cross-fabric bridge, operating transport, selecting providers or treating evidence as permission.
