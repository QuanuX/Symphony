# SHV interface authoring workflow

Read the selected module SPEC.md and its semantic owner first. Preserve frozen fixtures and their provenance. Edit the selected OWNER-INTERFACE.json, generate, review all three projections, and run its native interface and semantic tests plus affected qxctl tests. Do not infer a new embedded reader, writer admission, default version, user policy or authority from metadata generation. Install into a fresh prefix and verify receipt-owned declaration rejection and guarded uninstall before release.
