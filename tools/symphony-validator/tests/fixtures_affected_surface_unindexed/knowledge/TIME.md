# Symphony Temporal Semantics Contract

## Status and Authority

Canonical fixture contract owned by the common knowledge surface.

## Purpose

Prove that a valid repository includes a bounded temporal contract.

## Canonical UTC Profiles

Whole-second UTC and exact-nine-digit nanosecond UTC are distinct normalized profiles.

## Durable Timestamp Authority

The target host owns durable commit time; wall-clock text is not causal identity.

## Implementation and Schema Contract

Implementations validate real Gregorian dates without creating clock authority.

## Promotion Gate

This fixture creates no vector, engine, runtime service, or synchronization policy.
