# SQV administration transport support

C++26 internal build support. Common helpers preserve full uint64 through canonical decimal strings and opaque bytes through lower-case hex/chunks. Each compile target selects one exact namespace, module, engine and vector; its generated owner interface declares its finite operations. Process requests and responses use KnowledgeVectorEngine 0.2. Native handlers reside with SQMV, SQFV, SQTV, SQPV, SQDV and SQAV. No loading, provider routing, topology selection, credential lookup, payload relay or semantic dispatch across owners occurs.

Request payload 262144 bytes; envelope 524288; result 450000; five-second deadline. Native errors use fixed messages. Receipt/schema/response validation belongs to the qxctl consumer. Scripts and source generators are not runtime dependencies.
